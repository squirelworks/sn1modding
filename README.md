# SN1 Modding

Documentation and resources for modding **Subnautica** (the original game, often abbreviated SN1).

This repository collects guides, setup instructions, key concepts, and links for the modern Subnautica modding ecosystem centered around **BepInEx** + **Nautilus**.

## Quick Start

1. Install the [Subnautica BepInEx Pack](https://www.nexusmods.com/subnautica/mods/1108) (or from the [GitHub repo](https://github.com/toebeann/BepInEx.Subnautica)).
2. Install [Nautilus](https://www.nexusmods.com/subnautica/mods/1262) (or from [GitHub releases](https://github.com/SubnauticaModding/Nautilus/releases)).
3. Place mod DLLs in `Subnautica/BepInEx/plugins/`.

See the [docs/](docs/) folder for detailed guides.

## Notes

- **Nautilus** is the current recommended framework for the latest Subnautica version.
- Older **QModManager** / **SMLHelper** is only relevant for the legacy branch (no longer available on Steam as of late 2025).
- Always match your framework version to your game branch/version.
