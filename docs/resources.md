## Tools

- **Unity 2019.4.36** — For creating AssetBundles matching the game.
- **dnSpy / ILSpy** — For inspecting game assemblies.
- **Harmony** — Runtime patching.
- **AssetStudio / AssetRipper** — For extracting game assets.

## Related Games

- Subnautica: Below Zero uses a very similar modding setup (same Nautilus, slightly different templates).

## Learning Path Suggestion

1. Install BepInEx + Nautilus and a few popular mods.
2. Read the official Nautilus simple mod and prefab guides.
3. Create a minimal plugin that logs a message.
4. Experiment with a Harmony patch.
5. Add a custom item or console command.
6. Dive into AssetBundles if you need custom models.

Happy modding!
